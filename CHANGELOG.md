# Changelog

## v1.0.0 (2026-10-10)

First release.

- Live price card embed guide, with the light and dark themes and the one-month to five-year ranges.
- Static SVG chart images and sparklines.
- News feeds: RSS, Markdown write-ups, sitemaps, and category filters.
- Languages, share images, and agent files (llms.txt and llms-full.txt).
- Copy-ready examples for plain HTML, WordPress and Ghost, Markdown, React, Vue, and a Python RSS reader.
- A documentation site with live demos.
