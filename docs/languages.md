# Languages

Write-ups are also published in Spanish, French, German, Portuguese, Japanese, Chinese, and Arabic. Each language has its own address, and every version links to the others.

| Language | Code | Example address |
| --- | --- | --- |
| Spanish | `es` | `https://stocks.freetheai.org/es/news/<slug>` |
| French | `fr` | `https://stocks.freetheai.org/fr/news/<slug>` |
| German | `de` | `https://stocks.freetheai.org/de/news/<slug>` |
| Portuguese | `pt` | `https://stocks.freetheai.org/pt/news/<slug>` |
| Japanese | `ja` | `https://stocks.freetheai.org/ja/news/<slug>` |
| Chinese | `zh` | `https://stocks.freetheai.org/zh/news/<slug>` |
| Arabic | `ar` | `https://stocks.freetheai.org/ar/news/<slug>` |

The `<slug>` is the same as the English write-up's, so you can take any English link and add the language code in front of `/news/`.

Example, in Spanish:

```
https://stocks.freetheai.org/es/news/quantum-computing-stocks-hit-52-week-lows-amid-sector-cash-burn-and-macro-risks-5709b8
```

The price cards and chart images show the same numbers in every language.
