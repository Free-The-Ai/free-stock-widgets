# Examples

The [repository](https://github.com/Free-The-Ai/free-stock-widgets) has each example in its own folder.

| Example | What it is |
| --- | --- |
| [`plain-html`](https://github.com/Free-The-Ai/free-stock-widgets/tree/main/examples/plain-html) | One HTML page with price cards, a chart, and links to the news |
| [`wordpress-ghost`](https://github.com/Free-The-Ai/free-stock-widgets/tree/main/examples/wordpress-ghost) | The HTML block for a WordPress Custom HTML block or a Ghost HTML card |
| [`markdown`](https://github.com/Free-The-Ai/free-stock-widgets/tree/main/examples/markdown) | Chart images and sparklines for a README, wiki, or blog post |
| [`react`](https://github.com/Free-The-Ai/free-stock-widgets/tree/main/examples/react) | A `PriceCard` component for React |
| [`vue`](https://github.com/Free-The-Ai/free-stock-widgets/tree/main/examples/vue) | A `PriceCard` component for Vue 3 |
| [`python`](https://github.com/Free-The-Ai/free-stock-widgets/tree/main/examples/python) | A script that reads the RSS feed with the standard library |

Every example uses the same addresses as the [live price cards](live-price-card.md) and [chart images](chart-images.md).
