# FreeTheAI Stock Widgets

![FreeTheAI Stock Widgets](assets/banner.jpg)

FreeTheAI Stocks offers free market widgets you can put on any site: a live price card, static SVG charts, news feeds in RSS and Markdown, and share images. There is no key, no account, and nothing to sign up for.

This documentation shows each widget with a live demo, and the [examples](examples.md) show how to paste them into real pages.
